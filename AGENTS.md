# Правила работы

Читайте источники до написания технических утверждений; указывайте конкретные разделы. Не выдумывайте источники, характеристики, испытания и результаты ревью. Сохраняйте пользовательские изменения. Формулы проверяйте по источнику, размерности, допустимым входам и независимому примеру. Статус verified присваивается только при документированной проверке; самостоятельная повторная оценка моделью не является независимым экспертным ревью. При изменениях обновляйте метаданные и отчёты, запускайте соответствующие проверки. Не публикуйте внутренние материалы без разрешения владельца.
