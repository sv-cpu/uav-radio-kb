# Инженерная база знаний по радиосвязи БПЛА

Русскоязычный справочник в начальной стадии подготовки. Цель — статьи с проверяемыми источниками, воспроизводимые расчёты и пригодный для RAG корпус. Первая версия ещё не готова: см. [план и состояние](reports/plan.md).

Материалы: [основы радиосвязи](docs/01-radio-fundamentals/index.md), [распространение радиоволн](docs/02-wave-propagation/index.md), [антенны](docs/03-antennas/index.md), [радиооборудование](docs/04-radio-hardware/index.md), [каналы управления](docs/05-control-links/index.md), [учебный расчёт](docs/08-calculations/wavelength-example.md), [диагностика кабеля и антенны](docs/09-diagnostics/cable-antenna.md). Десять статей частей 1–2 имеют статус verified после документированного автоматизированного ревью; две статьи ожидают завершения проверки; 15 статей частей 3–5 — черновики. Человеческого экспертного ревью нет. Все статьи пока исключены из основного RAG-корпуса.

Согласованный [план 65 статей](reports/article-plan.md) разбит на 13 частей. Источники перечислены в [реестре](sources.yaml); собственные материалы и права на источники описаны в [LICENSES.md](LICENSES.md). При изменении статьи сверяйте её с источниками и обновляйте отчёт. Структурная проверка сама по себе не подтверждает физическую достоверность.

## Проверки и исследовательский экспорт

Нужен Python 3.10 или новее; текущие проверки используют только стандартную библиотеку. Из корня репозитория:

```text
python -m unittest discover -s tests -v
python -m scripts.validate
python -m scripts.export_rag --research
```

Последняя команда создаёт `build/research.jsonl` с предупреждением в каждой записи. Это экспериментальная выгрузка целых статей для разработки, не основной корпус. Без `--research` экспорт завершится с ошибкой: допуск в основной корпус и схема фрагментов ещё не реализованы. Валидатор проверяет соответствие статуса verified записи ревью и контрольной сумме статьи. Front matter записывается как JSON — подмножество YAML 1.2; текущий парсер не принимает произвольный YAML. Валидатор проверяет только перечисленные в его коде базовые поля, но не полную схему, ссылки и содержание.

Разделы 06–07 и 10–13 пока не наполнены. Не используйте этот снимок как законченную базу или источник нормативных требований.
