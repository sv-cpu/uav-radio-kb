# Инженерная база знаний по радиосвязи БПЛА

Русскоязычный справочник в начальной стадии подготовки. Цель — статьи с проверяемыми источниками, воспроизводимые расчёты и пригодный для RAG корпус. Первая версия ещё не готова: см. [план и состояние](reports/plan.md).

Материалы: [основы радиосвязи](docs/01-radio-fundamentals/index.md), [распространение радиоволн](docs/02-wave-propagation/index.md), [антенны](docs/03-antennas/index.md), [радиооборудование](docs/04-radio-hardware/index.md), [каналы управления](docs/05-control-links/index.md), [учебный расчёт](docs/08-calculations/wavelength-example.md), [диагностика кабеля и антенны](docs/09-diagnostics/cable-antenna.md). Шестнадцать статей имеют статус verified: десять частей 1–2 после документированного автоматизированного ревью, все пять статей части 3 и статья 4.1 после согласования владельцем; две статьи ожидают завершения проверки; девять статей частей 4–5 — черновики. Независимого внешнего экспертного ревью нет. Все статьи пока исключены из основного RAG-корпуса.

Согласованный [план 66 статей](reports/article-plan.md) разбит на 13 частей. Статьи обозначаются номером части и порядковым номером в ней, например 3.1 и 3.2; постоянный ID и путь статьи при этом сохраняются. Источники перечислены в [реестре](sources.yaml); собственные материалы — только для просмотра, копирование без разрешения запрещено ([LICENSE](LICENSE), [LICENSES.md](LICENSES.md)). При изменении статьи сверяйте её с источниками и обновляйте отчёт. Структурная проверка сама по себе не подтверждает физическую достоверность.

## Проверки и исследовательский экспорт

Нужен Python 3.10 или новее; текущие проверки используют только стандартную библиотеку. Из корня репозитория:

```text
python -m unittest discover -s tests -v
python -m scripts.validate
python -m scripts.export_rag --research
python -m scripts.prepare_pardai --as-of 2026-10-31
python -m scripts.build_site --base-url /uav-radio-kb
```

Обзорный HTML-сайт для проверки публикуется на GitHub Pages:
[https://sv-cpu.github.io/uav-radio-kb/](https://sv-cpu.github.io/uav-radio-kb/).
Сборка идёт автоматически при push в `main` (workflow `pages.yml`). Каталог `build/site` в Git не входит.

`export_rag --research` создаёт `build/research.jsonl` с предупреждением в каждой записи. Это экспериментальная выгрузка целых статей для разработки, не основной корпус. Без `--research` этот экспорт завершится с ошибкой: схема фрагментов ещё не реализована. `prepare_pardai` отдельно создаёт локальный пакет Markdown и манифест; на указанную дату основной пакет пуст. Подробнее — в [инструкции интеграции](rag/pardai-integration.md). Валидатор проверяет соответствие статуса verified записи ревью и контрольной сумме статьи. Front matter записывается как JSON — подмножество YAML 1.2; текущий парсер не принимает произвольный YAML. Валидатор проверяет только перечисленные в его коде базовые поля, но не полную схему, ссылки и содержание.

Разделы 06–07 и 10–13 пока не наполнены. Не используйте этот снимок как законченную базу или источник нормативных требований.
