## A. Содержание, которое должно быть в 3.1

### A1. Каркас выбора

- [x] В кратком ответе зафиксирован порядок: частоты/полоса → роль звена (борт/земля, TX/RX) → нужные направления → поляризация (со ссылкой на 3.3) → тип и диаграмма → согласование/фидер (ссылки на 3.4–3.5) → проверка установленной системы.
- [x] Явно сказано: имя типа не доказывает пригодность для данного аппарата или станции.
- [x] Ограничение «тип не задаёт совместимость и дальность» сформулировано инженерно в тексте; отдельный служебный блок «ответ агента / недопустимые выводы» из статьи убран (правила остаются в evaluation).

### A2. Типы конструкций (каждый пункт — для всех восьми типов или с явным «не рассматривается»)

Для диполя, монополя, patch, cloverleaf, helix, Yagi-Uda, рупора/отражателя, решётки:

- [x] Устройство без численных характеристик конкретного изделия.
- [x] Типичная ориентация / сектор (качественно): где максимум, где провалы.
- [x] Когда тип обычно рассматривают на **борту** vs на **земле** (качественно, без обещания дальности).
- [x] Ограничения и запрещённые выводы (не менее одного «нельзя» на тип).
- [x] Локатор первоисточника (раздел/страница), согласованный с `sources.yaml`.

Дополнительно проверить покрытие пробелов текущего текста:

- [x] Cloverleaf: зачем смотреть направление вращения — одной фразы + ссылка на 3.3 достаточно; не разворачивать теорию CP здесь.
- [x] Helix: осевой vs нормальный режим; «витой штырь ≠ осевая CP-спираль».
- [x] Patch: «панельная» маркировка ≠ известная конструкция внутри.
- [x] Решётка vs diversity / несколько антенн модема — различие сохранено и усилено примером «две антенны на плате ≠ фазированная решётка».
- [x] Yagi / рупор: роль преимущественно наземной направленной установки; для подвижного борта — оговорка о наведении.

### A3. Слой «БПЛА», который уместен именно в 3.1

Не каталог FPV-рецептов, а условия выбора типа:

- [x] Различены роли: бортовая антенна (меняется ориентация) и наземная (часто сектор/наведение).
- [x] Упомянуто, что управление, видео и телеметрия могут требовать **разных** антенн/трактов; детали каналов — в 5–7, здесь только следствие для выбора типа.
- [x] Крен/тангаж/рысканье: смена направления относительно провалов диаграммы и оси типа — качественно; расчёт ориентации — не здесь.
- [x] Экранирование корпусом / соседними элементами: «меняется окружение типа» + ссылка на 3.5 / 3.2, без методики измерения.
- [x] Запрет: не выводить радиус связи из типа антенны.

- [x] Чеклист ошибок сохранён и не противоречит A1.
