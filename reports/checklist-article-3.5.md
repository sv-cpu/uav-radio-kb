# Чеклист доработки статьи 3.5

Статья: [3.5 Размещение антенн, кабели и разъёмы](../docs/03-antennas/placement-cables.md) (`antenna-placement-cables`).

Назначение: установка антенно-фидерного тракта на БПЛА и на земле — размещение, паспортные кабели, разъёмы и учебный пересчёт длины — без подмены диаграммы, КСВН-формул и полной диагностики.

Статус: `draft` до согласования владельцем; `rag.include: false`. Независимое внешнее экспертное ревью не заявлялось. Служебные блоки «ответ агента» в текст не вносятся.

## Граница

В 3.5: размещение борт/земля; фидер как часть установленной системы; паспортные примеры кабелей и условия сравнения; радиусы/температура/мощность по паспорту; разъёмы и переходники качественно; учебный `L = a × l / 100`; отсылка к измерению сборки.

Не сюда: типы конструкций и таблица выбора типа (3.1); сечения/gain/EIRP (3.2); поляризация подробно (3.3); пересчёты КСВН/S11 (3.4); полный протокол диагностики (9.1); карточки изделий (13); универсальные «нормы» дБ/м или допуски разъёмов без паспорта.

## Содержание

- [x] Краткий ответ и порядок: роль/частота → размещение → кабель/длина → разъёмы → измерение сборки; не путать с усилением и дальностью.
- [x] Рамка БПЛА: борт (ориентация, корпус, маршрут) и земля (сектор, мачта, стационарный фидер).
- [x] Связь с 3.1/3.2: рабочий сектор углов, не перекрывать рабочую сторону; diversity ≠ фазированная решётка.
- [x] Частоты БПЛА: паспортная строка или измерение; 2 500 MHz ≠ 2 400 MHz; не экстраполировать RG-174 за заявленный диапазон.
- [x] Сохранены паспортные таблицы пяти кабелей с локаторами.
- [x] Разъёмы: серия/полярность/переходник; SMA и RP-SMA как пример несовместимости по центру; без выдуманных дБ потерь.
- [x] Формула: численные тесты есть; в тексте — «численно проверено, ревью статьи/формулы не завершено».
- [x] `related` и aliases расширены; карта ссылок в конце.
- [x] Evaluation `a29`–`a31`.
- [ ] Согласование владельцем и запись ревью (после явного одобрения).

## Не делать

- [x] Нет служебного блока инструкций агента.
- [x] Нет таблиц «типичных» потерь разъёмов без источника.
- [x] Нет обещаний дальности и универсальных норм КСВН.
