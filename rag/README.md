# Состояние экспорта

`python -m scripts.export_rag --research` создаёт детерминированный JSONL из целых статей и явно помечает непроверенные записи. Файл в `build/` не входит в Git. ID состоит из стабильного ID документа и суффикса `:whole`; при переименовании файла ID сохраняется, но поле пути меняется.

Это исследовательский прототип. Он не реализует смысловое разбиение, схему всех полей, привязку локаторов к фрагментам, манифест, инкрементальное удаление, Qdrant или контрольные вопросы. Основной экспорт намеренно закрыт до реализации проверки записей ревью. По этому прототипу нельзя делать вывод о качестве поиска или достоверности ответов.
