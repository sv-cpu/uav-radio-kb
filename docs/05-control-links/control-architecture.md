# Состав и функции канала управления

## Назначение и краткий ответ

Канал управления передаёт команды; телеметрия сообщает состояние. Они могут использовать общий транспорт либо независимые соединения.

## Контекст и объяснение

В PX4 Integrated Ground Control Stations, разделы Manual Control, Telemetry Link и Failsafes, ручное управление может передаваться сообщениями MAVLink по тому же каналу, что и телеметрия, либо через отдельный RC-сигнал. Эти варианты имеют разные общие точки отказа.

## Практическое применение

Для конкретной системы нарисуйте путь от органа управления до контроллера и обратный путь состояния: интерфейс, радиоустройства, протокол, источник питания и прошивка. Отметьте, какие части общие.

## Ограничения и типичные ошибки

Наличие двух потоков данных не означает физического резервирования. Поведение зависит от реализации и версии; пример PX4 main нельзя без проверки переносить на другую прошивку.
