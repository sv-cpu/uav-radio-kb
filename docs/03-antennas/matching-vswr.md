# Согласование, отражение и КСВН

## Что можно узнать из измерения

Измерение отражения показывает, какая часть падающей волны возвращается к измерительному порту от подключённого тракта. Его результат относится к **конкретной частоте, опорному импедансу и плоскости калибровки**. Он помогает обнаружить изменение согласования, но не измеряет диаграмму направленности, усиление или эффективность излучения антенны.

## Что происходит на границе тракта

Передатчик, кабель и антенна имеют входные и волновые импедансы. При несовпадении условий согласования часть падающей волны отражается. Импеданс включает активную и реактивную составляющие и зависит от частоты; подробное объяснение — в [статье об импедансе](../01-radio-fundamentals/power-voltage-impedance.md). Согласование в одной точке диапазона не гарантирует такого же результата на соседних частотах.

Сложение падающей и отражённой волн создаёт распределение напряжения вдоль линии. Коэффициент стоячей волны по напряжению (**КСВН**, английский VSWR) характеризует отношение максимума напряжения к минимуму в этой картине при соответствующих условиях измерения. Для пассивного случая значение начинается от 1; чем ближе к 1, тем меньше отражение в выбранной плоскости. Rohde & Schwarz, *Demystifying OTA testing*, §2.2.1, описывает VSWR и коэффициент отражения.

## S11, return loss и КСВН

| Представление | Что показывает | Как читать |
|---|---|---|
| S11 | Коэффициент отражения на порту при заданной системе измерения; комплексная величина содержит амплитуду и фазу | На экране часто показывают модуль в dB, а не полное комплексное значение; проверяйте обозначение и опорный импеданс |
| Return loss | Логарифмическая мера отражения, обычно выраженная положительным числом dB | Большее положительное значение соответствует меньшему отражению при принятом соглашении |
| КСВН / VSWR | Представление отражения через стоячую волну | Значение ближе к 1 означает меньшее отражение; это не процент эффективности антенны |

Разные обозначения описывают связанные свойства на одной плоскости, но не являются одинаковыми числами. В руководстве Keysight FieldFox B Series, глава 3, раздел Return Loss Measurements, отдельно оговаривается обычное использование положительного значения return loss. Сравнивая графики, проверяйте знак, единицы и масштаб, а также то, включена ли фаза.

## Как пересчитать КСВН и return loss

Для пассивной нагрузки обозначим модуль коэффициента отражения `ρ = |Γ|` и КСВН `K`. При одинаковой опорной плоскости и опорном импедансе `K = (1 + ρ) / (1 − ρ)`, а `ρ = (K − 1) / (K + 1)`. Положительный return loss `RL = −20 log₁₀(ρ) dB`; обратное преобразование: `ρ = 10^(−RL/20)`. Источник: Rohde & Schwarz, *RF Fundamentals Part 3*, слайды 18 и 30–31, Mismatch Chart. Модуль S11 в децибелах при том же соглашении равен **−RL**, а фаза при таком пересчёте теряется.

Учебный пример по таблице R&S: при `K = 1,5` получаем `ρ = (1,5 − 1)/(1,5 + 1) = 0,2`, затем `RL = −20 log₁₀(0,2) ≈ 14,0 dB`; модуль S11 в dB составляет около −14,0 dB. Это не измерение конкретной антенны. Значения таблицы округлены; тест допускает ±0,05 dB.

Границы: идеальное согласование `ρ = 0` соответствует `K = 1` и бесконечному RL; полное отражение `ρ = 1` соответствует `RL = 0 dB` и бесконечному КСВН. Для активной нагрузки или несовместимых определений опоры данные выражения не следует применять без другой модели. Реализация и тесты: `calculations/antenna.py`, `tests/test_antenna_calculations.py`.

## Почему кабель может изменить показание

Если калибровочная плоскость находится у передатчика, прибор видит всю цепь после неё: переходники, кабель, разъёмы и антенну. Сигнал доходит до антенны и возвращается по кабелю; потери и отражения тракта меняют результат у прибора. Больший положительный return loss на этом конце сам по себе не означает, что антенна стала лучше.

В опубликованном **учебном примере** Rohde & Schwarz, *Return loss and decoupling measurements*, §3.4.6, печатная стр. 16–17, антенна с условным return loss 14 dB и КСВН 1,5 рассматривается вместе с кабелем; при предположенном return loss кабеля 26 dB и потере 0,3 dB прибор может показать 12,5 dB на входе фидера. Это результат конкретной модели с указанными предпосылками, а не универсальная поправка для любого кабеля. В документе также отмечено, что другие неоднородности не учтены.

## Как организовать проверку

1. Отключите передатчик и соблюдайте допустимые уровни на измерительном входе согласно инструкции прибора. Осмотрите разъёмы и убедитесь в правильном типе переходников.
2. Определите вопрос: проверяется вся сборка у передатчика, только кабель или сама антенна? Выберите частотный диапазон, опорный импеданс и плоскость калибровки соответственно.
3. Откалибруйте прибор с учётом переходников по его руководству. Сохраните график по всему рабочему диапазону, а не только лучшее значение в одной точке.
4. Для сравнения антенны отдельно перенесите измерительную плоскость с корректной калибровкой. Измерение кабеля отдельно с известной нагрузкой и сравнение с прежней записью помогают отделять его влияние.
5. Запишите прибор, калибровку, частоту, кабель, соединения и условия монтажа. Дальнейшая последовательность приведена в [диагностике кабеля и антенны](../09-diagnostics/cable-antenna.md).

Keysight FieldFox B Series, глава 3, раздел Return Loss Measurements, описывает последовательность установки диапазона, калибровки и подключения; конкретные действия для другого прибора могут отличаться.

## Что не следует заключать

Хорошее согласование означает лишь малое отражение на выбранной плоскости. Согласованная нагрузка может поглощать мощность, не излучая её в нужном направлении; проверка диаграммы и эффективности требует других измерений. Отражение не заменяет двухпортовое измерение потерь кабеля. Универсальный порог «пригодно» без требований конкретной системы и полосы задавать нельзя.
